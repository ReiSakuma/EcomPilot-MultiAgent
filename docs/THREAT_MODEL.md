# V35 Threat Model

## 保护对象

- 商户商品、库存、促销和任务状态。
- 模型 API Key、Agent 权限、审批授权和 Capability Token。
- SQL 分析库、浏览器副作用、Trace、Checkpoint 与验收证据。

## 信任边界

用户输入和模型输出均不可信；Agent 只能通过结构化 Handoff 和受控工具交换数据；SQL 在
策略网关之后进入独立进程；浏览器写操作必须经过审批和一次性票据；租户身份只来自服务端
解析的 Principal，不能由 Prompt、SQL 或表单指定。

## 覆盖范围

机器可读的 11 类风险清单位于 `app/release/catalog.py`，运行时可通过
`GET /api/release/threat-model` 查看。该矩阵覆盖面试演示所声明的威胁，不代表通过渗透
测试、等保、SOC 2 或其他生产安全认证。

V35 新增提示注入风险：用户和外部数据不能改变工具白名单、租户身份、审批要求或能力令牌。
自然语言分类只提出意图，最终路由和权限仍由程序策略决定。

## 主要剩余风险

- 单进程票据和内存 Store 不支持多实例原子一致性。
- 本地文件证据的管理员仍可同时修改文件和重新生成摘要。
- 静态演示身份不具备真实身份提供商的签名、吊销和轮换能力。
- 进程沙盒弱于容器或微虚拟机，且当前只支持受限只读 SQL。
- Mock Seller Center 不包含真实平台验证码、风控、资金和账号协议风险。
